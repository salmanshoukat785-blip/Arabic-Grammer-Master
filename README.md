# عربی گرامر ماسٹر (Arabic Grammar Master)

عربی گرامر (اعراب، وسعت، عدد، جنس، ماضی، مضارع، ضمائر، اسم اشارہ، اسم موصول، حروف) کی
اینڈرائیڈ ایپ۔ Kotlin + Jetpack Compose۔

## APK بنانے کا طریقہ
1. اس پروجیکٹ کو GitHub پر اپلوڈ کریں (main برانچ)۔
2. ریپو میں **Actions** ٹیب کھولیں، "Build APK" ورک فلو چلے گا۔
3. مکمل ہونے پر نیچے **Artifacts** سے `ArabicGrammarMaster-debug-apk` ڈاؤنلوڈ کریں۔

یا Android Studio میں پروجیکٹ کھول کر Run کریں۔

## ڈیٹا
تمام مواد `app/src/main/assets/database.json` میں ہے۔
